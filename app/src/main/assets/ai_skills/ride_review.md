# Ride review
Start with the requested session, or query the latest COMPLETED session if unspecified. Retrieve ride_metrics once.
Assess duration, power coverage, NP versus average power, IF/TSS with the ride FTP, cadence and HR coverage. Distinguish ERG targets from measured power.
Discuss execution consistency with short SQL time buckets only if needed; averages conceal intervals. Missing HR or cadence must remain unknown.
Use work/estimated energy with assumptions. Identify interrupted recording, pauses and sensor gaps before judging fitness or pacing.
Base suggestions on the actual effort and user's stated goal; do not label a session unsuccessful from a single metric. If the intended workout is unknown, say so.
End with one useful adjustment for a comparable next session, not an unsolicited full workout plan.
